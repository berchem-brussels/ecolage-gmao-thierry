# Municipal CMMS (GMAO)

Technical management application for the municipal administration and the public social welfare centre: work requests, room and equipment booking, work follow-up, assets, preventive maintenance, stock and vehicles. It follows the "Municipal applications standard v3.2" (`STANDARD.md`, the French text prevails) and starts from template v3 1.1.0. Licence EUPL-1.2.

Version 0.7.4 (names of the location and category in the audit log detail; other features of 0.7.1): foundation (entities as data, accounts, roles per entity, active entity chosen in the header), register of places (sites, buildings, floors, rooms per entity, one photo per place, place types as a French and Dutch value list) and administration (instance settings, switchable modules, settings per entity, readable audit log, release notes) and request reference data (category tree with its tiles, priorities P1 to P4 and periods, working-day calendar and due-date simulator, per entity; "Modified on … by …" on each record and audit log limited to changed fields). Since 0.5.0: work requests (home page by role, Where, What, Description form, numbering per entity `AC-DI-2026-00001`, « My requests », read-only requests of the entity, accent-insensitive place search). Since 0.7.0: complete form (open requests in the same building and « Me too », « Danger » box, « For », preferred date, draft, questions per category, GDPR notices per entity).

Development, tests, installation and documentation: see `README.md` and `docs/en/`. Host address, ports and folders in this repository are example values (`192.0.2.10`, `monapp`).
