# Municipal CMMS (GMAO)

Technical management application for the municipal administration and the public social welfare centre: work requests, room and equipment booking, work follow-up, assets, preventive maintenance, stock and vehicles. It follows the "Municipal applications standard v3.3" (`STANDARD.md`, the French text prevails) and starts from template v3 1.1.0. Licence EUPL-1.2.

Version 0.21.5: the location proposed for a new request is confirmed with one click, requests already open at the same place or for the same problem are shown first, “My requests” shows the last activity, and the header fits on a tablet. Version 0.21.4: a typed date or time refused by the field is reported as soon as the field is left, and nothing is saved until it is corrected. Version 0.21.3: the technical department is notified of every request that reaches it (danger as absolute priority); a reopened or on-hold request reaches « Work finished » with its last task; an unretained typed date or time blocks saving; calendar icon on the left of the field. Version 0.21.2: on a computer, a date is typed in the field and the calendar opens through the icon (fix of « Terminer la tâche »). Version 0.21.1: a typed date or time is always the one saved (fix of « Terminer la tâche »). Version 0.21.0: technical department planning; the week or the day of workers and teams, tasks still without a date, conflicts (absent, non-working day, overloaded) and moving a task by drag and drop; workers' absences (leave, training, other, without the cause); actual start and end times of a task; the requester sees when the date of the intervention changes. Since 0.20.0, a request is split into tasks entrusted to workers or a team. The timed usability test protocol is in `docs/en/RECETTE-USAGE.md`.

Development, tests, installation and documentation: see `README.md` and `docs/en/`. Host address, ports and folders in this repository are example values (`192.0.2.10`, `monapp`).
