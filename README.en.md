# Municipal CMMS (GMAO)

Technical management application for the municipal administration and the public social welfare centre: work requests, room and equipment booking, work follow-up, assets, preventive maintenance, stock and vehicles. It follows the "Municipal applications standard v3.3" (`STANDARD.md`, the French text prevails) and starts from template v3 1.1.0. Licence EUPL-1.2.

Version 0.13.0: photo of the spot on a request record for the technical department, "Without photo" checkbox in Assets, phone header fitting 320 px (iPhone and Android), audit log without raw codes; since 0.12.0, help per screen ("Help" button on every screen, one sheet per screen in FR and NL with screenshots, "?" next to every field, help centre with search and printing, local FAQ per entity, resolved question turned into a FAQ entry); since 0.11.0, tickets ("Report" button on every screen, questions about the application handled by the entity's technical department, incidents, bugs and wishes by the administrator, Tickets screen, reading by the assistant); since 0.10.0 Microsoft 365 sign-in compatible with Portal; since 0.9.0 technical department (dashboard, filtered list, qualification, deadlines and delay); photos and PDFs attached to requests (0.8.0); full request form (0.7.0); intervention requests numbered per entity, "My requests" (0.5.0); request reference data (categories, priorities P1 to P4, deadlines, calendar); places with photos; administration (parameters, modules, settings per entity, audit log, release notes); core (entities, accounts, roles per entity, active entity). The French text prevails.

Development, tests, installation and documentation: see `README.md` and `docs/en/`. Host address, ports and folders in this repository are example values (`192.0.2.10`, `monapp`).
